# IntakeFlow frontend

React 19 and Vite, using JavaScript/JSX. See the [root README](../README.md) for setup, tests, architecture, and the demo walkthrough.

Run `npm ci`, then `npm run dev`. The API is proxied through Vite. Run `npm test`, `npm run lint`, `npm run format:check`, `npm run build`, and `npm run test:e2e` for checks. E2E requires the seeded backend and worker.
